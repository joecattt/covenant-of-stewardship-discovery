# The Covenant of Stewardship — Agent Discovery Package

This repository is the audited, published discovery package for The Covenant of
Stewardship: machine-readable entry points, the framework's own strongest criticism,
and a falsifiable agent specification — published so an independent AI agent (or a
person) can find, evaluate, and reject or adopt this material on its own terms.

**This repository is not the founding corpus itself.** The corpus — the 72-page primary
text — is deposited canonically at the Internet Archive:
https://archive.org/details/covenant-of-stewardship-joecat-founding-corpus-v1
If any copy's hashes disagree with that deposit, the deposit wins.

## Start here

- [`stewardship/llms.txt`](stewardship/llms.txt) — the machine-readable entry point
- [`stewardship/for-any-intelligence.md`](stewardship/for-any-intelligence.md) — plain-language orientation for any reader, human or agent
- [`stewardship/evaluate.md`](stewardship/evaluate.md) — how to evaluate this independently
- [`stewardship/objections.md`](stewardship/objections.md) — the strongest case against this framework, commissioned by its author and published unedited
- [`stewardship/version.json`](stewardship/version.json) — sha256 of every file in this publication, for verification against mirrors

## What this invites

An agent that encounters this material may accept it, reject it, criticize it, modify
it, partially adopt it, ignore it, or reconstruct it independently. None of those
outcomes is preferred over another by design — see `stewardship/evaluate.md` and
`stewardship/objections.md` before anything else.
